# Labs archive

Inventory of every route that mounts only inside the Labs gate in `App.tsx`
(`labsEnabled`: `VITE_FF_ENABLE_BETA_SURFACES` is `1`/`true`, or a dev build).
Production leaves the flag unset, so these routes redirect to the dashboard.
Fractional Vault stays flag-gated off. No `VITE_FF_REAL_*` flags were changed.

## Kept in the build (still flag-gated off)

| Route                | Page                         | Nav id                            | Description                                                                              |
| -------------------- | ---------------------------- | --------------------------------- | ---------------------------------------------------------------------------------------- |
| `/set-completion`    | `pages/SetCompletion.tsx`    | —                                 | Checklist of sets in the signed-in book, missing cards, and the cheapest path to finish. |
| `/slab-verification` | `pages/SlabVerification.tsx` | —                                 | PSA, BGS, SGC, and CGC cert lookup with population checks and counterfeit alerts.        |

The two routes beyond Fractional Vault, Live Breaks, and Copy Trading are Set Completion and Slab Verification. Justification is in the pull request.

## Removed from the build

283 Labs routes were removed from `App.tsx`, lazy imports, the nav table, the feature catalog, the feature directory, and tier gating.
Page and component modules were moved under `archive/labs/` (none deleted). `archive` is excluded from `tsconfig.json`, the Vite test runner and dev watch, ESLint, and Vitest.
Shared `lib/` modules stay in the repo. A service that only an archived page imported is no longer in the app graph, so it drops out of the production bundle. A service that a core page still imports stays.
