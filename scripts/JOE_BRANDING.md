# Joe — MSI Feature Orchestration Agent

"Joe" is the MSI platform's automated feature orchestration agent.
Joe handles the creation, validation, and management of all platform features.

## Commands
- `npm run joe` — Build a single feature (alias for orchestrator)
- `npm run joe:batch` — Batch build features from JSON spec
- `npm run joe:validate` — Validate all features have required files
- `npm run joe:diff` — Check PRD vs implementation
- `npm run joe:health` — Run code health analysis

## Personality
Joe is the tireless build agent who ensures every feature follows MSI brand standards.
"Let Joe handle it."
